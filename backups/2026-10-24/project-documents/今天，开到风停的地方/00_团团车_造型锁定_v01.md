# 团团车｜造型锁定 v01

日期：2026-10-22　用途：《今天，开到风停的地方》全片唯一车辆
状态：设计规范（尚未出图，未获用户确认）

## 一、必须成立的三件事

1. 观众一眼认出这是团团变的：墨质、耳形、唯一铜铃与单条红穗必须在车上连续存在。
2. 它是一辆能真的载两只猫出游的小车：座位、方向盘、轮距、挡风都要符合坐姿，不靠镜头藏结构。
3. 变形过程可见：身体鼓出轮形→车体展开→座舱形成→铃与穗落位。不用闪光、白场或烟尘跳过过程。

## 二、比例与结构

| 部位 | 规格 | 说明 |
|---|---|---|
| 总长 | 约 2.2 米 | 以两猫幼猫比例坐姿为参照，刚好双座 |
| 总宽 | 约 1.25 米 | 并排两座，肩不挤 |
| 座高 | 约 0.55 米 | 猫坐进后前爪自然搭在车沿 |
| 轮径 | 约 0.42 米 | 四个实心轮，轴距约 1.45 米 |
| 挡风 | 一掌高 | 极矮的透明墨膜，不遮猫脸 |
| 方向盘 | 单圈小盘 | 直径约 0.22 米，位置偏驾驶座一侧 |

## 三、外观

- **车身**：深黑半哑光活墨，延续团团皮肤。中暗部保留，高光是柔和湿润的宽反光，不是镜面车漆。车身侧面可见极细的墨流纹，静止时几乎不动，行驶时才缓慢向后流动。
- **座舱**：奶油色织物座垫与靠背，蜂蜜金同族的暖色，少量旧铜包边。座垫有被压过的软痕，不是崭新展车。
- **识别件**：车头正中**唯一**铜铃，与团团颈铃同款同尺寸；铃侧挂**单条**红穗，长度约到车头下沿，行驶时向后飘。
- **耳形后视镜**：车头两侧各一只，形取自团团耳形，可小幅转动。转弯时会朝内侧偏，像在留意乘客。
- **轮与底盘**：素黑实心轮，浅铜轮毂，胎面细横纹。底盘低，坐进去是"陷进去"而不是"架在上面"。
- **车尾**：短、微微上翘，收得圆。没有尾翼、排气管、车牌、贴纸、文字、品牌标。

## 四、禁令

- 不在车头另挂狗头、犬面、第二张脸或装饰眼。
- 不改跑车/卡丁车比例：不加长车头、不压低车顶到看不见猫、不加宽体套件。
- 铜铃只有一枚，红穗只有一条。
- 车身不发光、不喷墨、不出现魔法阵。
- 不用别人的车改色冒充，必须能从团团身体追到每一个部件。
