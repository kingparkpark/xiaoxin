# 电影镜头 Skill

把一句基础画面描述或一张视频参考图转换为完整电影镜头方案，并生成可直接用于 AI 视频模型的 Prompt。Skill 可以自动匹配导演视觉参考，也可以执行用户指定的导演方向。

## 最少需要提供什么

只需要画面内容，例如：`沙漠中，一个人抬头看到庞然巨兽站在眼前。`

情绪、限制条件、导演、平台、时长、比例和参考图都是可选信息。缺少平台、时长或比例时，Skill 不会追问，而会在 Prompt 外给出推荐参数。

## 导演风格模式

- **自动匹配**：选择最适合的一位导演参考，解释原因，提供两个简短备选，并直接采用首选生成。
- **指定导演**：用户点名内置导演时，直接调用对应档案。
- **名单外导演**：临时建立同结构的风格画像，正常生成，完成后询问是否加入正式库；未经确认不会保存。
- **不用导演参考**：回退到通用摄影决策规则。

第一版每次只使用一位导演的视觉逻辑。导演姓名用于解释参考方向；可执行 Prompt 会转换成焦距、构图、机位、运镜、光线、色彩和节奏等具体指令。


## 文生视频与图生视频

- 没有参考图：完整描述人物、环境、构图、动作、运镜和光线。
- 有参考图：默认锁定身份、服装、环境和起始构图，重点描述动作、镜头运动、环境变化与连续性。

## 参数与Prompt

平台、时长和比例可以帮助模型适配、动作节奏与构图，但不是必填项。默认在 Prompt 外列出缺失项的推荐值，不机械地把平台名、秒数和画幅写进正文。只有平台执行确实需要时，才给出包含相关信息的平台适配版 Prompt，并说明原因。

## 单镜头与多镜头

Skill 会先判断镜头结构：简单画面默认单镜头；出现“发现—反应—行动”、人物对峙、环境揭示或地点/时间变化时，自动使用2–3镜多镜头。

多镜头输出包含逐镜 Prompt、建议时长、切点、转场、连续性约束和一段可直接复制的合并 Prompt。用户可以随时说“改为单镜头”或“改为3镜分镜”覆盖自动判断。

## 输出

1. 风格匹配
2. 镜头决策
3. 不依赖导演姓名的可执行 Prompt
4. 必要的负面约束
5. 缺失项的推荐参数
6. 名单外导演的入库询问

## 结构

- `SKILL.md`：调用入口与输出约定
- `references/input-routing.md`：可选输入与文生/图生模式
- `references/shot-structure.md`：单镜头/多镜头判断与分镜输出
- `references/visual-style-tags.md`：统一视觉标签
- `references/director-matching.md`：自动、指定与临时导演路由
- `references/directors/`：21位内置导演档案
- `references/prompt-workflow.md`：Prompt 转换流程
- 其他 `references/`：光学、景别、构图、机位、运镜、光线和决策规则
- `ROADMAP.md`：后续扩展路线

原则：叙事目的先于器材参数；可观察指令先于风格名称；参考图和用户限制高于风格倾向。

## 分享与安装

分享时发送完整的 `cinematic-shot-design` 文件夹或对应 zip 压缩包，不要只发送 `SKILL.md`，否则导演档案和摄影规则不会随技能生效。

接收方将整个文件夹放入自己的 Codex Skills 目录：

- macOS / Linux：`~/.codex/skills/cinematic-shot-design/`
- Windows：`%USERPROFILE%\.codex\skills\cinematic-shot-design\`

重新打开 Codex 后，可直接说“使用电影镜头 Skill”或输入 `$cinematic-shot-design` 调用。上传 GitHub 时，以本文件夹为仓库根目录；其他人可以下载仓库 zip，或把仓库克隆到上述 Skills 目录。

公开发布前请自行选择并添加许可证；没有许可证的公开仓库默认不等于允许他人复制、修改和再发布。
