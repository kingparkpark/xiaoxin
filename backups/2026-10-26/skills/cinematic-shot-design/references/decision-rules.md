# 镜头决策规则

先确定观众此刻需要感受或知道什么，再选择工具。

| 目标 | 推荐起点 | 避免 |
|---|---|---|
| 建立宏大世界 | 远景，18–24mm，深景深，固定或缓升 | 浅景深特写丢失空间 |
| 人物融入环境 | 全/中景，28–35mm，前中后景调度 | 长焦把环境压成装饰 |
| 自然对话 | 中近景，40–65mm，平视，克制移动 | 无动机环绕与频繁跳焦段 |
| 私密脆弱 | 近景，65–100mm，浅景深，柔侧光，极缓推近 | 无意图的强广角贴脸 |
| 威胁逼近 | 负空间/遮挡，中长焦压缩，固定或缓推 | 过早暴露威胁 |
| 混乱失控 | 24–35mm近身、手持、遮挡、不完整构图 | 所有元素同时剧烈运动 |
| 冷静客观 | 35–50mm，平视，稳定构图，固定 | 夸张浅景深和主观畸变 |
| 权力优势 | 低机位、中心/占据构图、较硬光 | 忽略表演关系机械套用 |
| 孤独疏离 | 远景/负空间，固定，人物偏置或被框住 | 近景填满画面 |
| 梦境记忆 | 选择性浅景深、柔光、漂移或非自然色 | 堆满所有“梦幻”标签 |

## 序列规则

- 建立镜头回答“在哪里”，中景回答“做什么”，近景回答“感受什么”；不必机械排序。
- 镜头变化应来自信息、情绪、权力或空间关系变化。
- 连续切换需有足够景别、角度或构图差异，避免近似画面跳切。
- 建立轴线、眼线、运动方向与光线基准；打破时帮助观众重新定位。
- 动作镜头先展示清楚动作路径，再追求速度感。
