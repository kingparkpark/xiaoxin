# 普通描述到电影镜头 Prompt

## 转换顺序

先依照 [shot-structure.md](shot-structure.md) 决定单镜头或多镜头，再按以下流程转换，避免把生成设置和画面指令混在一起。

1. **生成元数据**：读取可选的平台、时长、比例和参考图。已知的平台用于适配表达方式，已知时长限制动作数量和节奏，已知比例用于构图；缺失时不追问，准备在 Prompt 外给出推荐。参考图存在时切换为图生视频，并锁定既有身份、服装、环境和起始构图。
2. **结构与设计决策**：保留人物、动作、场景、时间、关键道具和不可变元素；选择单镜头或2–3镜多镜头；明确每一镜的叙事任务，再决定景别、构图、主体位置、空间层次、焦段、机位、运镜、光线及连续性。
3. **可执行 Prompt**：单镜头写成一段连续指令。多镜头先写逐镜独立 Prompt，再按镜头顺序合并为一段可复制 Prompt；每镜都重复必要的角色、空间和方向锚点。默认不把平台、时长或比例写进 Prompt；只有它们对目标模型的时序或画幅理解有实质帮助时，才另给“平台适配版 Prompt”并说明原因。
4. **负面约束**：只列本次画面可能出现且会破坏意图的失败预防，例如人物变脸、错误屏幕方向或无动机运镜。
5. **推荐参数**：仅为用户未提供的平台、时长或比例单列推荐及简短理由；它们不属于可执行 Prompt 正文。

## 多镜头合并句式

`共享连续性设定；镜头1：[建立/揭示]；硬切到镜头2：[反应/准备]；硬切到镜头3：[行动/余波]；转场与屏幕方向规则；负面约束。`

“硬切到镜头2”是给支持镜头切换的模型的自然语言提示。若平台只能稳定生成单镜头，应使用逐镜 Prompt 分别生成，再按剪辑说明拼接。

## 句式

`[景别与主体]，[场景与动作]；[构图和空间层次]；[焦段/透视与景深]；[机位与有动机的运镜]；[光源、方向、质地、反差、色彩]；[情绪与质感]；[连续性约束]。`

可观察指令优先于“cinematic, masterpiece, 8K”等质量词。不要同时要求固定与复杂移动、深景深与极浅景深、正午硬光与阴天柔光。

## 示例：文生视频

输入：`女孩深夜在空车站等人，很不安。`

可执行 Prompt：`夜晚空旷车站的中远景，女孩独自站在画面右侧，左侧大片负空间延伸至黑暗站台，远处灯管形成消失点；35mm自然广角，中等景深，平视机位，镜头从稳定远观极缓推近；冷白顶灯形成断续光区，脸部有微弱暖色手机反光，低调高反差；她反复望向隧道入口，衣着、站位方向与灯光连续一致。`

负面约束：`避免无动机环绕、夸张手持、人物变脸、额外乘客、文字乱码。`

推荐参数：`平台无关：画面只依赖通用的单镜头、缓推和负面约束表达，未出现需要特定平台字段的要求；6–8 秒，以一次望向隧道和一次极缓推近完成不安的积累；16:9，为站台纵深和左侧留白保留空间。`

## 示例：图生视频

输入：`参考图中红色雨衣的女孩站在雨夜便利店门口；她抬头看向街对面驶过的出租车。`

可执行 Prompt：`保持参考图中女孩的面容、红色雨衣、便利店门口位置与起始构图；雨水沿招牌边缘滴落，她缓慢抬头，视线追随街对面掠过的出租车尾灯；从现有中景平稳横移少许，保持女孩在画面右侧与门框形成的遮挡关系；湿地反射霓虹红绿光，出租车经过时暖黄车灯短暂扫过她的脸，雨势、光向和人物朝向连续一致。`

负面约束：`避免改变女孩外观或雨衣颜色、重构便利店环境、跳切、额外人物和无动机镜头旋转。`

推荐参数：`平台无关：参考图锁定与连续性描述可由通用图生视频流程表达，未出现必须依赖特定平台的字段；5–6 秒，容纳一次抬头与一次车辆掠过；竖幅 9:16，保留人物、门框和街对面的纵向关系。`
