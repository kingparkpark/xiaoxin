# 统一视觉风格标签

使用受控、可观察的标签将用户画面与导演档案放在同一套坐标中。每个标签都必须能落到景别、焦段、构图、机位、运镜、光线、色彩或调度中的至少一项具体选择；不能转换为镜头指令的抽象词不使用。

| 类别 | 受控值 | 对可见选择的影响 |
|---|---|---|
| 叙事功能 | 建立世界、揭示信息、制造悬念、呈现关系、压迫角色、释放情绪、完成转折 | 决定优先交代环境、隐藏信息、看反应或展示动作路径。 |
| 情绪 | 悬疑、压迫、亲密、疏离、宏大、荒诞、哀伤、兴奋、平静 | 选择留白或贴近、稳定或不稳定、低调或明亮的光线。 |
| 空间 | 封闭、开放、纵深、扁平、有序、混乱、分层、受阻隔 | 决定镜头是否看见边界、前中后景、遮挡和消失点。 |
| 尺度 | 亲密、自然、宏大 | 分别倾向近景与浅景深、中景自然关系、远景与人物相对环境的大小。 |
| 透视 | 广角纵深、自然透视、长焦压缩 | 分别用短焦近景拉开空间、约 40–55mm 保持比例、长焦压平人物与背景。 |
| 构图 | 中心、对称、负空间、遮挡、框中框、层次、偏置 | 规定主体位置、留白方向、前景物和建筑线条如何组织。 |
| 镜头稳定性 | 固定、平滑、手持 | 固定镜头制造观察；平滑轨道或推拉维持控制；手持只在需要身体感或失控时使用。 |
| 运镜 | 不动、缓推、拉远、横移、跟拍、升降、受控摇镜 | 每种运动必须给出起止、方向、速度和叙事动机；不动也是明确选择。 |
| 光线 | 柔光、硬光、低调、高调、侧光、背光、实景光源 | 决定阴影边缘、反差、脸部可读性与可见光源位置。 |
| 色彩 | 去饱和冷色、暖色孤岛、互补撞色、单色组织、自然中性 | 决定主辅色如何落在服装、光源、环境和反射上，而非只写情绪词。 |
| 动作强度 | 静止、细微动作、克制行动、持续行动、爆发行动 | 限制单个镜头中可读动作的数量、速度和幅度，并决定固定观察、跟拍或手持是否合理。 |
| 表面质感 | 洁净平滑、自然粗粝、潮湿反光、烟雾颗粒、工业磨损 | 落在墙面、服装、地面、空气介质和反光的具体描述中；只在画面事实或叙事目标需要时使用。 |
| 节奏 | 停驻、缓慢积累、流动、突然断裂、急促 | 限制镜头数量、动作数量、停顿长度与运镜速度。 |
| 人物调度 | 独处、对峙、并行、群体层次、前后景分离、进出画面 | 决定人物相对位置、视线、屏幕方向、遮挡和谁先行动。 |

## 使用规则

1. 每次提取与当前画面相关的少量标签，不用完整标签表堆砌风格。
2. 先记录硬性限制和画面事实，再选择标签；任何标签不得覆盖锁定人物、环境、构图或明确的用户意图。
3. 若两个标签产生冲突，回到叙事功能选择一个明确的可执行方案，例如“固定观察”或“跟拍陪伴”，而不是同时写两者。
