# 墨团团项目协作备份

2026-10-14 本地整理，等待上传公开 GitHub。

## 新对话使用
先读 AGENTS.md，随后按任务读取 skills；参考规则最新条目优先。历史中的方案不等于用户定稿，真实完成状态以明确确认及文件证据为准。

## 内容
- conversations：本机可取得、与本项目工作目录或已知项目会话匹配的用户和助手消息，Markdown 与 JSONL。不是摘要替代原文。
- skills：项目创作技能及图像生成、技能创建方法的文本快照。
- rules：共享确认卡和导演清单，可能包含旧状态，须结合最新规则。
- deliverables：本工作区提示词、学习记录与说明。

## 范围与限制
不是整个账号全部聊天导出。云端或已删除历史、本机未保存的早期内容无法保证齐全。系统/开发者消息、隐藏推理、工具原始日志、凭据、内嵌图片编码未导出；用户消息中的项目规则保留。原始视频和参考图片不在本次文本备份中，路径只作历史线索，不保证其他设备可访问。

用户明确授权公开项目对话及资料。备份过滤常见凭据格式；没有读取 auth.json、浏览器登录数据或账号数据库。未额外授予第三方素材再分发许可。
